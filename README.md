# Global Weather Dashboard (Flask)

A simple weather dashboard built using Flask and the OpenWeather API.  
Users can enter any city and see real-time weather information including temperature, humidity, wind speed, and a description of current conditions.

---

## Features

- Fetches live weather data using OpenWeather API  
- Clean and simple UI  
- Flask backend with Jinja templates  
- Error handling for invalid cities
